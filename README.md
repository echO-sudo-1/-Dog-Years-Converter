# -Dog-Years-Converter
A lightweight CLI tool written in C++ that converts your dog's age into human years based on standard canine age calculations.
## 📌 How It Works

1. **First 2 Years:** Count as **21 human years**.
2. **Each Subsequent Year:** Counts as **4 human years**.
3. **Calculation Formula:**
   $$\text{Human Years} = 21 + (\text{Dog Age} - 2) \times 4$$

Getting Started
Prerequisites
Any standard C++ compiler (e.g., g++, clang++, or MSVC).

Execution Steps
Clone the repository:


git clone [https://github.com/echO-sudo-1/dog-years-converter.git](https://github.com/echO-sudo-1/dog-years-converter.git)
cd dog-years-converter

Compile the program:
g++ -o dog_years main.cpp
Run the executable:

Linux/macOS:

./dog_years
Windows:
dog_years.exe
